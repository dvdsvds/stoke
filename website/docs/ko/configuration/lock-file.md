# 락 파일

`.stoke/lock.toml`은 각 빌드에서 사용된 도구와 의존성의 정확한 버전을 기록합니다. 재현성을 보장해서, 다른 개발자(또는 CI)가 프로젝트를 빌드해도 같은 버전을 쓰게 됩니다.

## 목적

- **재현성**: 여러 머신에서 동일한 버전
- **속도**: 락이 일치하면 의존성 재해석 생략
- **감사 가능성**: 빌드가 정확히 어떤 버전을 쓰는지 확인 가능

## 위치
myproject/
├── stoke.toml
└── .stoke/
└── lock.toml       # ← 락 파일

## 커밋해야 할까요?

**애플리케이션은 예**, 라이브러리는 아니오.

- **애플리케이션**: `lock.toml`을 git에 커밋하세요. 모든 개발자와 CI가 같은 버전을 쓰도록 버전을 고정합니다.
- **라이브러리**: 커밋하지 마세요. 라이브러리 사용자가 새 버전으로 해석하게 두세요.

라이브러리라면 `.gitignore`에 추가하세요:
.stoke/lock.toml
