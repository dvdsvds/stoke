빌드·실행·스캐폴딩

stoke는 Python, Java, C, C++, Go, Rust, Kotlin, C#, Ruby, PHP, JavaScript, TypeScript의 개발 워크플로우를 하나로 통일합니다 — CLI 하나, stoke.toml 하나로 모든 프로젝트.

시작하기 → GitHub에서 보기
MIT 라이선스 관리자 권한 불필요 Windows · Linux · macOS
stoke.toml 
[project]
name = "myapp"
version = "0.1.0"

[targets.myapp]
language = "cpp"
sources = ["src/**/*.cpp"]

$ stoke build
Build complete: myapp
$ stoke run
Hello from stoke!

필요한 모든 것을, 하나의 인터페이스로

내부적으로 stoke는 pip, javac, Maven, gcc/clang, vcpkg, go build, cargo, npm을 그대로 씁니다 — 그냥 일관되게 감쌀 뿐입니다.

다중 언어

12개 언어를 완전히 같은 명령어로 빌드합니다 — 생태계마다 다시 배울 필요 없음.

언어 설치

stoke install로 Python/JDK/gcc/Go/Rust/Node.js 설치 — 프로젝트 안에만, PATH 변경 없음.

프레임워크 스캐폴딩

Spring Boot, FastAPI, Flask, Django, Gin, Next.js, Actix-web, Ktor, ASP.NET Core 등.

빠름

헤더 의존성 추적을 통한 증분 컴파일. 바뀐 것만 다시 빌드됩니다.

간단함

프로젝트 전체를 위한 stoke.toml 하나 — 언어별 설정 파일을 여러 개 다룰 필요 없음.

Watch & Hot-reload

파일 변경 시 자동 재빌드, 장시간 실행되는 서버는 프로세스 재시작까지.

IDE 연동

빌드할 때마다 VSCode / Eclipse / IntelliJ 설정을 자동 생성합니다.

빌드 프로파일

Debug / Release / 커스텀 프로파일, 각자의 플래그와 define을 가질 수 있습니다.
