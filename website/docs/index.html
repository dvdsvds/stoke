[project]

[targets.myapp]
language = "cpp"

Everything you need, one interface

Under the hood stoke drives pip, javac, Maven, gcc/clang, vcpkg, go build, cargo, and npm — it just wraps them consistently.

Multi-language

Build 12 languages with the exact same commands — no context switching between ecosystems.

Language installation

Install Python/JDK/gcc/Go/Rust/Node.js via stoke install — scoped to the project, no PATH changes.

Framework scaffolding

Spring Boot, FastAPI, Flask, Django, Gin, Next.js, Actix-web, Ktor, ASP.NET Core, and more.

Fast

Incremental compilation with header dependency tracking. Only what changed gets rebuilt.

Simple

One stoke.toml for the whole project — no per-language config files to juggle.

Watch & hot-reload

Auto-rebuild on file changes, with optional process restart for long-running servers.

IDE integration

Auto-generates VSCode / Eclipse / IntelliJ configs on every build.

Build profiles

Debug / Release / custom profiles, each with their own flags and defines.
