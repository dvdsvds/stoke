Quick Start

This guide walks you through creating and building your first stoke project.

Create a new project

Use stoke init to scaffold a new project interactively:

mkdir myapp
cd myapp
stoke init

The wizard will ask:

  • Project name
  • Language (Python, Java, C, C++, Go, Rust, Kotlin, C#, Ruby, PHP, JavaScript, TypeScript)
  • Version requirements
  • Dependencies

It generates:

  • stoke.toml — project configuration
  • src/ — source directory with a hello-world file

Build

stoke build

Output: Building 'myapp' (cpp)... Using cpp compiler 15.2.0 Compiled 1 file(s) Build complete: myapp

Build artifacts land in .stoke/.

Run

stoke run

Output: Running: ...\myapp.exe Hello from stoke!

Watch mode

Auto-rebuild on file changes:

stoke watch

Press Ctrl+C to stop.

Hot-reload

Rebuild and restart the process automatically:

stoke hot-reload

Useful for servers or long-running processes.

Language-specific quick starts

Python

[project]
name = "myapp"
version = "0.1.0"

[targets.myapp]
language = "python"
python_version = "3.12"
entry = "src/main.py"

[targets.myapp.deps]
requests = "*"

stoke build     # Creates venv, installs deps
stoke run       # Runs src/main.py

Java

[project]
name = "myapp"
version = "0.1.0"

[targets.myapp]
language = "java"
java_version = "25"
sources = ["src/main/java/**/*.java"]
main_class = "com.example.Main"

stoke build     # Compiles .java files
stoke run       # Runs main_class

C

[project]
name = "myapp"
version = "0.1.0"

[targets.myapp]
language = "c"
sources = ["src/**/*.c"]

stoke build     # Compiles + links
stoke run       # Runs the executable

C++

[project]
name = "myapp"
version = "0.1.0"

[targets.myapp]
language = "cpp"
sources = ["src/**/*.cpp"]

stoke build
stoke run

Go

[project]
name = "myapp"
version = "0.1.0"

[targets.myapp]
language = "go"

stoke build     # go build
stoke run       # runs the compiled binary

Rust

[project]
name = "myapp"
version = "0.1.0"

[targets.myapp]
language = "rust"

stoke build     # cargo build --release
stoke run       # runs the compiled binary

Kotlin

[project]
name = "myapp"
version = "0.1.0"

[targets.myapp]
language = "kotlin"
java_version = "21"

stoke build     # gradlew build -x test
stoke run       # gradlew run (needs the application plugin)

C

[project]
name = "myapp"
version = "0.1.0"

[targets.myapp]
language = "csharp"

stoke build     # dotnet build
stoke run       # runs the built binary

[project]

[targets.myapp]
language = "ruby"
entry = "src/main.rb"

stoke build     # bundle install (if Gemfile exists)
stoke run       # ruby src/main.rb (or bundle exec ruby)

PHP

[targets.myapp]

stoke run       # php src/main.php

JavaScript

[project]
name = "myapp"
version = "0.1.0"

[targets.myapp]
language = "javascript"

TypeScript

stoke run       # runs src/main.ts via tsx
