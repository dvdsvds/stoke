빠른 시작

첫 stoke 프로젝트를 만들고 빌드하는 과정을 안내합니다.

새 프로젝트 생성

stoke init으로 대화형으로 새 프로젝트를 스캐폴딩하세요:

mkdir myapp
cd myapp
stoke init

마법사가 다음을 물어봅니다:

  • 프로젝트 이름
  • 언어 (Python, Java, C, C++, Go, Rust, Kotlin, C#, Ruby, PHP, JavaScript, TypeScript)
  • 버전 요구사항
  • 의존성

생성되는 것:

  • stoke.toml — 프로젝트 설정
  • src/ — hello-world 파일이 있는 소스 디렉토리

빌드

stoke build

출력: Building 'myapp' (cpp)... Using cpp compiler 15.2.0 Compiled 1 file(s) Build complete: myapp

빌드 산출물은 .stoke/에 생성됩니다.

실행

stoke run

출력: Running: ...\myapp.exe Hello from stoke!

Watch 모드

파일 변경 시 자동 재빌드:

stoke watch

Ctrl+C로 중지합니다.

Hot-reload

자동으로 재빌드하고 프로세스를 재시작:

stoke hot-reload

서버나 장시간 실행되는 프로세스에 유용합니다.

언어별 빠른 시작

Python

[project]
name = "myapp"
version = "0.1.0"

[targets.myapp]
language = "python"
python_version = "3.12"
entry = "src/main.py"

[targets.myapp.deps]
requests = "*"

stoke build     # Creates venv, installs deps
stoke run       # Runs src/main.py

Java

[project]
name = "myapp"
version = "0.1.0"

[targets.myapp]
language = "java"
java_version = "25"
sources = ["src/main/java/**/*.java"]
main_class = "com.example.Main"

stoke build     # Compiles .java files
stoke run       # Runs main_class

C

[project]
name = "myapp"
version = "0.1.0"

[targets.myapp]
language = "c"
sources = ["src/**/*.c"]

stoke build     # Compiles + links
stoke run       # Runs the executable

C++

[project]
name = "myapp"
version = "0.1.0"

[targets.myapp]
language = "cpp"
sources = ["src/**/*.cpp"]

stoke build
stoke run

Go

[project]
name = "myapp"
version = "0.1.0"

[targets.myapp]
language = "go"

stoke build     # go build
stoke run       # runs the compiled binary

Rust

[project]
name = "myapp"
version = "0.1.0"

[targets.myapp]
language = "rust"

stoke build     # cargo build --release
stoke run       # runs the compiled binary

Kotlin

[project]
name = "myapp"
version = "0.1.0"

[targets.myapp]
language = "kotlin"
java_version = "21"

stoke build     # gradlew build -x test
stoke run       # gradlew run (needs the application plugin)

C

[project]
name = "myapp"
version = "0.1.0"

[targets.myapp]
language = "csharp"

stoke build     # dotnet build
stoke run       # runs the built binary

Ruby

[project]
name = "myapp"
version = "0.1.0"

[targets.myapp]
language = "ruby"
entry = "src/main.rb"

stoke build     # bundle install (if Gemfile exists)
stoke run       # ruby src/main.rb (or bundle exec ruby)

PHP

[project]
name = "myapp"
version = "0.1.0"

[targets.myapp]
language = "php"
entry = "src/main.php"

stoke build     # composer install (if composer.json exists)
stoke run       # php src/main.php

JavaScript

[project]
name = "myapp"
version = "0.1.0"

[targets.myapp]
language = "javascript"
entry = "src/main.js"

stoke build     # npm install (if package.json exists)
stoke run       # node src/main.js

TypeScript

[project]
name = "myapp"
version = "0.1.0"

[targets.myapp]
language = "typescript"
entry = "src/main.ts"

stoke build     # npm install
stoke run       # runs src/main.ts via tsx
